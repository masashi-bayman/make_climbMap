# make_climbMap - 登山マップ作成ツール

GPXの山行データから、**地名ラベル入りの登山ルートマップ画像（透過PNG）** と
**各スポットの到着時刻テキスト** を作成するデスクトップアプリです。

YouTubeの縦動画（720x1280相当）の右側に重ねる用途を想定したサイズで出力されます。

## 全体の流れ

```
YAMAP                ヤマレコ                本アプリ
┌──────────┐        ┌──────────────┐       ┌──────────────────┐
│ 山行記録から │  →   │ GPXを取り込んで │  →   │ 地名入りGPXを読込  │
│ GPXをDL     │        │ 地名入りGPXに   │       │ → 地図画像＋時刻   │
└──────────┘        │ 変換してDL      │       │   テキストを出力    │
                     └──────────────┘       └──────────────────┘
```

### 1. YAMAPからGPXをダウンロード

1. YAMAPの自分の活動日記（山行記録）を開く
2. 「GPXダウンロード」でGPXファイルを保存する

※ この時点のGPXには軌跡と時刻は入っていますが、**地名は入っていません**。

### 2. ヤマレコで地名入りGPXに変換

1. ヤマレコにログインし、YAMAPでダウンロードしたGPXを取り込む
   （山行記録の作成画面などからGPXをアップロード）
2. ヤマレコが通過した山頂・分岐などの地名を自動で付与してくれる
3. その記録から**地名入りのGPX**を再ダウンロードする

※ 地名の自動付与はヤマレコでしかできないため、この工程は手作業です。
　地名はGPXの `<wpt>` タグ（またはトラックポイントの `name`）として入ります。

### 3. 本アプリで地図を作成

地名入りGPXを読み込むと、軌跡・地名ラベル・各スポットの到着時刻（JST）が
自動で表示されます。回転・余白・ラベル位置を調整して保存してください。

## インストール（venv使用）

Python 3.10 以上が必要です。依存パッケージは仮想環境（venv）に入れるため、
システムのPython環境を汚しません。

### Windows

```bat
git clone https://github.com/masashi-bayman/make_climbMap.git
cd make_climbMap
setup.bat
```

または手動で:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### macOS / Linux

```bash
git clone https://github.com/masashi-bayman/make_climbMap.git
cd make_climbMap
./setup.sh
```

または手動で:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 起動

### Windows

`run.bat` をダブルクリック、またはコマンドで:

```bat
run.bat

REM 起動と同時にGPXを読み込む
run.bat 山行データ.gpx
```

### macOS / Linux

```bash
./run.sh

# 起動と同時にGPXを読み込む
./run.sh 山行データ.gpx
```

※ venvを自分で有効化している場合は `python main.py` でも起動できます。

## 使い方

1. **GPXを開く** — 地名入りGPXファイルを選択すると即プレビューが表示されます
2. **スポット一覧で編集** — 画面右にGPX内の地名スポットが一覧表示されます
   - **名前を編集**: 入力欄を書き換えて Enter（または他の欄をクリック）すると
     地図のラベルと到着時刻テキストに即反映されます
   - **表示/非表示**: チェックを外すと、そのスポットは地図と到着時刻テキスト
     から除外されます（不要な通過点を消したいときに）
3. **回転** — `0° / 90° / 180° / 270°` ボタン、または任意の角度を入力して「適用」
   （縦長画面に収まる向きに調整します）
4. **表示範囲** — 地図を**ドラッグすると移動**、**マウスホイールで拡大縮小**
   できます（カーソル位置を中心にズーム）。「リセット」で初期表示に戻ります
5. **ラベル調整** — 地名ラベルはマウスで**ドラッグして移動**できます。
   マーカーの真上に近づけるとX座標がスナップし、引き出し線が垂直になります。
   表示範囲や矢印を変更して再描画しても、調整したラベル位置は維持されます
   （回転を変えた場合はリセットされます）
6. **方向矢印**（任意） — 「位置をクリックで指定」を押してから地図上をクリック
   すると矢印が置かれます。**↑↓←→ボタン**で向きを一発指定でき、細かい角度は
   数値入力（度・反時計回り）+ Enter でも調整できます。「消去」で削除できます
7. **保存** — GPXファイルと同じ場所に `output_YYYYMMDD` フォルダが作られ、
   以下の2ファイルが保存されます
   - `hiking_track_map_*.png` — 地図画像（透過PNG、動画への重ね合わせ用）
   - `spot_times_*.txt` — スポット到着時刻の一覧（下部テキスト欄の内容。
     保存前に自由に編集できます）

## ファイル構成

```
make_climbMap/
├── main.py                 # 起動スクリプト
├── requirements.txt
└── climbmap/
    ├── app.py              # Tkinter GUI（画面・操作）
    ├── gpx.py              # GPX解析（軌跡・地名・到着時刻の抽出）
    ├── rendering.py        # 地図の描画（matplotlib）
    ├── geometry.py         # 座標回転ユーティリティ
    ├── fonts.py            # 日本語フォントの自動検出
    └── __main__.py         # python -m climbmap 用
```

## 補足

- 地図の左下に**方位記号（N）**が表示されます。回転を変えると北の向きも
  それに合わせて回ります
- 日本語フォントは環境から自動検出します（Windows: Yu Gothic / MS Gothic、
  macOS: Hiragino、Linux: Noto Sans CJK JP など）
- 地名ウェイポイントの `[かな]` 表記は自動で除去されます
- 往復ルートで同じ地名が2回現れる場合は、行き（最初の通過）のみ採用されます
- 到着時刻は「軌跡上でそのスポットに最も近い地点の時刻」から推定しています
