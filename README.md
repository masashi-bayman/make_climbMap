# make_climbMap - 登山マップ作成ツール

GPXの山行データから、**地名ラベル入りの登山ルートマップ画像（透過PNG）** と
**各スポットの到着時刻テキスト** を作成するデスクトップアプリです。

YouTubeの縦動画（720x1280相当）の右側に重ねる用途を想定したサイズで出力されます。

## 全体の流れ

スポット（地名）を用意する方法は2通りあります。
**方法Aならヤマレコを経由せず、YAMAPだけで完結します。**

```
【方法A】YAMAPのチェックポイントを貼り付ける（おすすめ・ヤマレコ不要）

  YAMAP                             本アプリ
  ┌────────────────┐      ┌──────────────────────┐
  │ GPXをダウンロード    │  →   │ GPXを読み込む             │
  │ チェックポイント欄を  │  →   │ 貼り付けて「解析」→ 時刻から │
  │ コピー              │      │ 座標を割り出しスポット作成    │
  └────────────────┘      └──────────────────────┘

【方法B】ヤマレコで地名を付与する（従来どおり）

  YAMAP              ヤマレコ                本アプリ
  ┌──────────┐    ┌──────────────┐    ┌────────────┐
  │ GPXをDL     │ →  │ 地名入りGPXに    │ →  │ そのまま読み込む │
  └──────────┘    │ 変換してDL       │    └────────────┘
                    └──────────────┘
```

### 1. YAMAPからGPXをダウンロード（共通）

1. YAMAPの自分の活動日記（山行記録）を開く
2. 「GPXダウンロード」でGPXファイルを保存する

※ この時点のGPXには軌跡と時刻は入っていますが、**地名は入っていません**。

### 方法A: YAMAPのチェックポイントからスポットを作成

1. 同じ活動日記の**チェックポイント（コースタイム）欄をそのままコピー**する
2. 本アプリでGPXを開き、「**YAMAPのチェックポイントから作成**」を押す
3. コピーした内容を貼り付けて「解析する」→ 作成されるスポットの一覧を確認
4. 「置き換えて作成」で反映

貼り付けたテキストから**スポット名と時刻**を読み取り、その時刻に対応する
軌跡上の地点を探して座標を決めます。ヤマレコを経由する必要はありません。

コピーしたテキストは、次のように時刻・所要分・種別・スポット名が
並んだ形になっていれば解析できます（余分な行があっても構いません）。

```
11:47
28
12:15
23
滝
落ヶ滝
›
13:46
14:19
156
山頂
天狗岩
›
```

### 方法B: ヤマレコで地名入りGPXに変換

1. ヤマレコにログインし、YAMAPでダウンロードしたGPXを取り込む
   （山行記録の作成画面などからGPXをアップロード）
2. ヤマレコが通過した山頂・分岐などの地名を自動で付与してくれる
3. その記録から**地名入りのGPX**を再ダウンロードする

※ 地名はGPXの `<wpt>` タグ（またはトラックポイントの `name`）として入ります。
　アプリはどちらの形式も読み取ります。

### 2. 本アプリで地図を作成

軌跡・地名ラベル・各スポットの到着時刻（JST）が表示されます。
回転・表示範囲・ラベル位置を調整して保存してください。

## インストール（venv使用）

Python 3.10 以上が必要です。依存パッケージは仮想環境（venv）に入れるため、
システムのPython環境を汚しません。

### Windows

```bat
git clone https://github.com/masashi-bayman/make_climbMap.git
cd make_climbMap
setup.bat
```

または手動で:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### macOS / Linux

```bash
git clone https://github.com/masashi-bayman/make_climbMap.git
cd make_climbMap
./setup.sh
```

または手動で:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 起動

### Windows

`run.bat` をダブルクリック、またはコマンドで:

```bat
run.bat

REM 起動と同時にGPXを読み込む
run.bat 山行データ.gpx
```

### macOS / Linux

```bash
./run.sh

# 起動と同時にGPXを読み込む
./run.sh 山行データ.gpx
```

※ venvを自分で有効化している場合は `python main.py` でも起動できます。

## 使い方

0. **サイトを開く**（準備） — 「YAMAP」「ヤマレコ」ボタンで各サイトをブラウザ
   で開けます。GPXのダウンロードや地名付与の作業にすぐ移れます。
   「URL設定」で自分のマイページや活動日記のURLに変更でき、次回以降も保持されます
   （設定は `~/.climbmap/settings.json` に保存されます）
1. **GPXを開く** — GPXファイルを選択すると即プレビューが表示されます。
   地名が入っていないGPX（YAMAPから直接ダウンロードしたもの）の場合は、
   「**YAMAPのチェックポイントから作成**」でスポットを作成してください
2. **スポット一覧で編集** — 画面右にGPX内の地名スポットが一覧表示されます
   - **名前を編集**: 入力欄を書き換えて Enter（または他の欄をクリック）すると
     地図のラベルと到着時刻テキストに即反映されます
   - **表示/非表示**: チェックを外すと、そのスポットは地図と到着時刻テキスト
     から除外されます（不要な通過点を消したいときに）
3. **回転** — `0° / 90° / 180° / 270°` ボタン、または任意の角度を入力して「適用」
   （縦長画面に収まる向きに調整します）
4. **表示範囲** — 地図を**ドラッグすると移動**、**マウスホイールで拡大縮小**
   できます（カーソル位置を中心にズーム）。「リセット」で初期表示に戻ります
   - **余白の調整**: 地図（グレー領域）の**端にカーソルを合わせるとリサイズ
     カーソルに変わり、ドラッグでその辺の余白を伸縮**できます。余白が大きく
     なりすぎたときは端を内側にドラッグして詰めてください。保存される画像の
     縦横比も表示範囲に合わせて変わります
5. **ラベル・マーカー調整** — 地名ラベルも**スポットのマーカー（青丸）**も
   マウスで**ドラッグして移動**できます。引き出し線は両方に追従します
   - ラベルをマーカーの真上に近づけるとX座標がスナップし、線が垂直になります
   - マーカーを動かすと一覧のその行に「戻す」ボタンが出て、GPX上の実際の位置に
     復帰できます（「マーカー位置を全て戻す」で一括リセット）
   - マーカーの移動量は回転前の座標で保持するため、**回転を変えても位置調整は
     維持されます**（ラベル位置は回転を変えるとリセットされます）
   - マーカーを動かしても到着時刻は変わりません（GPXの実座標から算出済みのため）
6. **方向矢印**（任意） — 「位置をクリックで指定」を押してから地図上をクリック
   すると矢印が置かれます。**↑↓←→ボタン**で向きを一発指定でき、細かい角度は
   数値入力（度・反時計回り）+ Enter でも調整できます。「消去」で削除できます
7. **保存** — GPXファイルと同じ場所に `output_YYYYMMDD` フォルダが作られ、
   以下の2ファイルが保存されます
   - `hiking_track_map_*.png` — 地図画像（透過PNG、動画への重ね合わせ用）
   - `spot_times_*.txt` — スポット到着時刻の一覧（下部テキスト欄の内容。
     保存前に自由に編集できます）

   保存後のダイアログで「はい」を選ぶと保存先フォルダが開きます。
   **「保存先を開く」**ボタンでも、いつでもエクスプローラー（macOSはFinder）で
   開けます（保存済みならその画像を選択した状態、未保存ならGPXのある場所）

## ファイル構成

```
make_climbMap/
├── main.py                 # 起動スクリプト
├── requirements.txt
└── climbmap/
    ├── app.py              # Tkinter GUI（画面・操作）
    ├── gpx.py              # GPX解析（軌跡・地名・到着時刻の抽出）
    ├── rendering.py        # 地図の描画（matplotlib）
    ├── geometry.py         # 座標回転ユーティリティ
    ├── fonts.py            # 日本語フォントの自動検出
    ├── yamap.py            # YAMAPチェックポイントの解析・スポット作成
    ├── settings.py         # リンクURLなどの設定の保存・読み込み
    └── __main__.py         # python -m climbmap 用
```

## 補足

- 「方位記号(N)」にチェックを入れると地図の左下に**方位記号**が表示されます
  （デフォルトは非表示）。回転を変えると北の向きもそれに合わせて回ります
- 日本語フォントは環境から自動検出します（Windows: Yu Gothic / MS Gothic、
  macOS: Hiragino、Linux: Noto Sans CJK JP など）
- 地名ウェイポイントの `[かな]` 表記は自動で除去されます
- 往復ルートで同じ地名が2回現れる場合は、行き（最初の通過）のみ採用されます
- 到着時刻の求め方は作成方法によって異なります
  - 地名入りGPXの場合: 軌跡上でそのスポットに最も近い地点の時刻
  - YAMAPのチェックポイントから作成した場合: 貼り付けた時刻をそのまま使用
    （その時刻に対応する軌跡上の地点を座標として採用）
- 泊まりの山行で時刻が翌日に戻る場合も、日をまたいだものとして扱います
- 貼り付けた時刻が軌跡の時間帯から30分以上離れている場合は、解析結果に
  注意メッセージが表示されます（GPXと活動日記が別の山行の可能性があります）
