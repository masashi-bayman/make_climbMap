# make_climbMap - 登山マップ作成ツール

GPXの山行データから、**地名ラベル入りの登山ルートマップ画像（透過PNG）** と
**各スポットの到着時刻テキスト** を作成するデスクトップアプリです。

YouTubeの縦動画（720x1280相当）の右側に重ねる用途を想定したサイズで出力されます。

## 全体の流れ

```
YAMAP                ヤマレコ                本アプリ
┌──────────┐        ┌──────────────┐       ┌──────────────────┐
│ 山行記録から │  →   │ GPXを取り込んで │  →   │ 地名入りGPXを読込  │
│ GPXをDL     │        │ 地名入りGPXに   │       │ → 地図画像＋時刻   │
└──────────┘        │ 変換してDL      │       │   テキストを出力    │
                     └──────────────┘       └──────────────────┘
```

### 1. YAMAPからGPXをダウンロード

1. YAMAPの自分の活動日記（山行記録）を開く
2. 「GPXダウンロード」でGPXファイルを保存する

※ この時点のGPXには軌跡と時刻は入っていますが、**地名は入っていません**。

### 2. ヤマレコで地名入りGPXに変換

1. ヤマレコにログインし、YAMAPでダウンロードしたGPXを取り込む
   （山行記録の作成画面などからGPXをアップロード）
2. ヤマレコが通過した山頂・分岐などの地名を自動で付与してくれる
3. その記録から**地名入りのGPX**を再ダウンロードする

※ 地名の自動付与はヤマレコでしかできないため、この工程は手作業です。
　地名はGPXの `<wpt>` タグ（またはトラックポイントの `name`）として入ります。

### 3. 本アプリで地図を作成

地名入りGPXを読み込むと、軌跡・地名ラベル・各スポットの到着時刻（JST）が
自動で表示されます。回転・余白・ラベル位置を調整して保存してください。

## インストール

Python 3.10 以上が必要です。

```bash
git clone https://github.com/masashi-bayman/make_climbMap.git
cd make_climbMap
pip install -r requirements.txt
```

## 起動

```bash
python main.py

# または、起動と同時にGPXを読み込む
python main.py 山行データ.gpx

# パッケージとしての起動も可能
python -m climbmap
```

## 使い方

1. **GPXを開く** — 地名入りGPXファイルを選択すると即プレビューが表示されます
2. **回転** — `0° / 90° / 180° / 270°` ボタン、または任意の角度を入力して「適用」
   （縦長画面に収まる向きに調整します）
3. **余白** — 上下左右の余白を軌跡サイズに対する倍率で指定して「適用」
   （数値入力後に Enter でも適用されます）
4. **ラベル調整** — 地名ラベルはマウスで**ドラッグして移動**できます。
   マーカーの真上に近づけるとX座標がスナップし、引き出し線が垂直になります。
   余白や矢印を変更して再描画しても、調整したラベル位置は維持されます
   （回転を変えた場合はリセットされます）
5. **方向矢印**（任意） — 「位置をクリックで指定」を押してから地図上をクリック
   すると矢印が置かれます。角度（度・反時計回り）を変えて「描画」で向きを調整、
   「消去」で削除できます
6. **保存** — GPXファイルと同じ場所に `output_YYYYMMDD` フォルダが作られ、
   以下の2ファイルが保存されます
   - `hiking_track_map_*.png` — 地図画像（透過PNG、動画への重ね合わせ用）
   - `spot_times_*.txt` — スポット到着時刻の一覧（下部テキスト欄の内容。
     保存前に自由に編集できます）

## ファイル構成

```
make_climbMap/
├── main.py                 # 起動スクリプト
├── requirements.txt
└── climbmap/
    ├── app.py              # Tkinter GUI（画面・操作）
    ├── gpx.py              # GPX解析（軌跡・地名・到着時刻の抽出）
    ├── rendering.py        # 地図の描画（matplotlib）
    ├── geometry.py         # 座標回転ユーティリティ
    ├── fonts.py            # 日本語フォントの自動検出
    └── __main__.py         # python -m climbmap 用
```

## 補足

- 日本語フォントは環境から自動検出します（Windows: Yu Gothic / MS Gothic、
  macOS: Hiragino、Linux: Noto Sans CJK JP など）
- 地名ウェイポイントの `[かな]` 表記は自動で除去されます
- 往復ルートで同じ地名が2回現れる場合は、行き（最初の通過）のみ採用されます
- 到着時刻は「軌跡上でそのスポットに最も近い地点の時刻」から推定しています
